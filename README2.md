Лабораторная работа №2: Библиотека (Tagless Final)

Описание



Это вторая лабораторная работа по функциональному программированию.  

Реализована та же библиотека, что и в первой работе, но в стиле Tagless Final.



&#x20;Что сделано



\- \[x] Библиотека с функциями:

&#x20; - выдача книги (borrowBook)

&#x20; - возврат книги (returnBook)

&#x20; - следующий день (nextDay)

&#x20; - показать состояние (showState)



\- \[x] Использован Tagless Final стиль:

&#x20; - трейт Console\[F\[\_]] для ввода/вывода

&#x20; - трейт Library\[F\[\_]] для операций библиотеки

&#x20; - `given инстансы для IO

&#x20; - extension методы для удобной конвертации строк



\- \[x] Консольное меню с выбором действий



Структура проекта

src

Monad.scala-Reader, Writer, State, IO

Domain.scala-типы: Book, Reader2, Config, State

Logic.scala-логика: LibraryReader, LibraryState2

TaglessLibrary.scala-Tagless Final реализация
